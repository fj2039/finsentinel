## What's in them

**Milestone 1** sets up the problem and the first baselines: majority class and TF-IDF with logistic regression on Financial PhraseBank.

**Milestone 2** compares zero-shot against few-shot prompting, with confusion matrices and top-word analysis per sentiment class. The core finding starts here: the dominant failure mode is neutral sentences being predicted as positive, and few-shot prompting substantially reduces it.

**Milestone 3** adds chain-of-thought prompting and tests generalisation on FiQA, the noisier dataset. It also covers the FinSentinel web application.

**The presentation** is the final 10-slide summary of all six tiers.
